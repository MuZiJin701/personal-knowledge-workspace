# micro、mcedit 与 helix：终端编辑器使用指南

## 1. 快速选择

| 编辑器 | 定位 | 适合场景 |
|---|---|---|
| `micro` | 操作接近普通编辑器 | 新手、日常编辑、远程服务器 |
| `mcedit` | Midnight Commander 自带的轻量编辑器 | 临时修改配置文件 |
| `helix` | 面向代码的模态编辑器 | 长期进行终端编程 |

启动方式：

```bash
micro file.txt
mcedit file.txt
hx file.txt
```

也可以直接输入编辑器名称打开空白文件。

## 2. micro

### 基本操作

`micro` 默认可直接输入文字，支持鼠标，使用方式最接近图形界面编辑器。

| 操作 | 快捷键 |
|---|---|
| 保存 | `Ctrl-S` |
| 退出 | `Ctrl-Q` |
| 查找 | `Ctrl-F` |
| 替换 | `Ctrl-H` |
| 撤销 | `Ctrl-Z` |
| 重做 | `Ctrl-Y` |
| 复制 / 粘贴 / 剪切 | `Ctrl-C` / `Ctrl-V` / `Ctrl-X` |
| 查看帮助 | `Ctrl-G` |
| 打开命令栏 | `Ctrl-E` |

命令栏可以执行编辑器命令，例如：

```text
help                 # 查看帮助
set tabsize 4        # 设置 Tab 宽度
set ft python        # 设置文件类型
vsplit               # 垂直分屏
hsplit               # 水平分屏
```

### 记忆重点

- 不熟悉终端编辑器时优先使用 `micro`。
- `Ctrl-E` 是进入高级功能的入口。
- 遇到快捷键不确定时按 `Ctrl-G` 查看帮助。

## 3. mcedit

`mcedit` 是 Midnight Commander（命令 `mc`）中的编辑器，界面底部会显示主要功能键。

### 基本操作

| 操作 | 快捷键 |
|---|---|
| 保存 | `F2` |
| 退出 | `F10` |
| 标记文本 | `F3` |
| 替换 | `F4` |
| 复制选区 | `F5` |
| 移动选区 | `F6` |
| 查找 | `F7` |
| 删除选区 | `F8` |
| 打开菜单 | `F9` |
| 取消当前操作 | `Esc` |

### 使用流程

```text
1. mcedit file.txt
2. 直接输入或使用方向键移动
3. F2 保存
4. F10 退出
```

如果终端或笔记本电脑无法发送功能键，可尝试 `Fn+F2`、`Fn+F10`，或使用终端的 Esc 组合键。

### 记忆重点

- `mcedit` 功能少、启动快，适合服务器上的临时修改。
- 需要文件管理、目录浏览时，可以使用 `mc`，选中文件后按 `F4` 编辑。
- 不要把它当作完整 IDE；复杂代码编辑应选择 `micro` 或 `helix`。

## 4. helix

`helix` 是模态编辑器，默认进入普通模式。它的核心思路是“先选择，再执行操作”。

### 三种常用模式

| 模式 | 作用 | 进入方式 |
|---|---|---|
| 普通模式 | 移动、选择、删除、复制 | `Esc` |
| 插入模式 | 输入文字 | `i`、`a`、`o` |
| 命令模式 | 保存、退出、执行命令 | `:` |

### 普通模式快捷键

| 操作 | 快捷键 |
|---|---|
| 进入插入模式 | `i` |
| 在光标后输入 | `a` |
| 在下一行输入 | `o` |
| 上下左右移动 | `k` / `j` / `h` / `l` |
| 按单词移动 | `w` / `b` / `e` |
| 选择当前行 | `x` |
| 删除选区 | `d` |
| 修改选区并输入 | `c` |
| 复制选区 | `y` |
| 粘贴 | `p` |
| 撤销 / 重做 | `u` / `U` |
| 回到普通模式 | `Esc` |

### 命令模式

按 `:` 后输入：

```text
:write          # 保存
:quit           # 退出
:write-quit     # 保存并退出
:quit!          # 放弃修改并退出
:open file.txt  # 打开文件
```

### 记忆重点

- 刚启动时不要直接输入文字，先按 `i` 进入插入模式。
- 按 `Esc` 回到普通模式，再使用移动、选择和删除操作。
- `Space` 是 Helix 的功能菜单入口；可按 `Space` 查看当前可用操作。
- `hx --health` 可检查语言服务器和编辑环境。

## 5. 通用工作流

```text
打开文件 → 编辑 → 保存 → 检查内容 → 退出
```

建议：

- 修改配置前先备份，至少确认文件路径正确。
- 保存后重新查看关键内容，避免误删或格式错误。
- 远程服务器临时修改：`mcedit`。
- 希望简单易用：`micro`。
- 希望熟练使用键盘和代码功能：`helix`。

## 6. 一句话记忆

`micro` 像普通编辑器，`mcedit` 适合快速改文件，`helix` 适合模态化代码编辑。
