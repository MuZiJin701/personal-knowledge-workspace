# 公众号发布素材

## 基本信息

- 标题：手机、Windows 与 Linux 云服务器协同使用 Codex
- 作者：按公众号后台默认作者填写即可
- 封面图：[codex三端协同架构图-公众号.png](../assets/codex三端协同架构图-公众号.png)
- 正文：优先打开 `公众号正文-富文本复制页.html`，点击“复制排版后的正文”，再粘贴到公众号正文编辑器。该页面会把样式写入正文元素，避免公众号丢失网页样式。
- 备用：如果自动复制失败，保持页面正文选中，按 `Ctrl+C`，再回到公众号按 `Ctrl+V`。

## 发布步骤

1. 在公众号后台标题框填写标题。
2. 作者按需要填写；摘要可留空，或填写：`手机发任务，Windows 做连接和代理，Linux 云服务器运行 Codex。`
3. 打开 `公众号正文-富文本复制页.html`。
4. 点击页面顶部“复制排版后的正文”。如果提示自动复制失败，按 `Ctrl+C`。
5. 回到公众号正文编辑器，按 `Ctrl+V`。
6. 检查架构图是否显示；如果没有显示，点击编辑器图片位置重新上传 `../assets/codex三端协同架构图-公众号.png`。
7. 上传同一张架构图作为封面图，或按公众号后台要求裁剪。
8. 点击“预览”，在手机上检查标题、图片、代码块和段落间距。
9. 确认无误后，再点击“发表”。

## 注意

- 不要把真实服务器 IP、用户名、私钥或私钥口令填入文章。
- 正文中的 `<你的服务器IP>`、`<你的Linux用户名>` 等占位符必须保留，发布前不要替换成真实敏感信息。
- 公众号编辑器通常不会执行 Mermaid，所以发布正文使用架构 PNG 图和普通文字流程；Mermaid 版本仍保留在原 Markdown 文档中。
