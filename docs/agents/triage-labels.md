# Triage Labels

Matt Pocock 技能使用以下五个 canonical triage role；GitHub Issues 直接使用相同字符串。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已明确，可交给 agent |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不处理 |

如果未来改用其他 issue tracker，只需修改右侧标签映射和 `docs/agents/issue-tracker.md`，不要混用两套词汇。
