# 工作区运行术语

本上下文定义工作区运行规则中需要稳定复用的概念。

## Language

**对话驱动的知识工作区**：承载大量 ChatGPT/Codex 对话任务中的知识问答、问题解决和按需产出。一次对话可以生成持久化产物，也可以只保留在线程中。
_Avoid_：通用个人工作区、知识库

**持久化产物**：具体任务明确需要长期保留的文档、代码或附件。
_Avoid_：对话记录、线程归档

**对话任务**：在 ChatGPT/Codex thread 中完成的一次工作；其存在不要求创建仓库文件。
_Avoid_：文档任务、Issue

**跟踪任务**：需要后续跟进、协作或分阶段实施，并由 Issue 管理生命周期的工作。
_Avoid_：普通问答、对话任务

**知识主题**：一组围绕同一主题组织、值得长期保留的持久化产物。
_Avoid_：对话分类、任务目录

**临时材料**：任务执行期间可重建或无需长期保留的中间文件。
_Avoid_：持久化产物
**领域上下文**：工作区运行规则或某个知识主题中需要稳定复用的一组专属术语。
_Avoid_：目录分类、主题索引

**工作区运行规则**：约束工作流程、文档职责和协作方式的一组约定。
_Avoid_：记忆

**技能产物**：执行技能后按该技能与当前任务约定生成的文件或目录。
_Avoid_：持久化产物
