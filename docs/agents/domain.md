# Domain Docs

本工作区包含多个独立知识主题，领域文档采用按需维护的多上下文约定。

## 阅读顺序

1. 从根目录 `CONTEXT-MAP.md` 定位与当前任务相关的上下文。
2. 阅读该上下文的 `CONTEXT.md`，并使用其中定义的规范术语。
3. 阅读主题目录中与当前问题相关的知识文档。
4. 如果存在相关 ADR，再读取其约束和背景。

地图未登记相关上下文或文件不存在时静默继续；只有稳定术语或真实决策已经形成时才创建对应文件。

## 布局

```text
/
├── CONTEXT-MAP.md
├── docs/agents/CONTEXT.md
└── knowledge/<topic>/
    ├── CONTEXT.md             # 按需创建
    └── docs/adr/              # 按需创建
```

`CONTEXT.md` 只定义领域术语和边界，不记录实现步骤。ADR 只用于难以逆转、缺少背景会令人意外且经过真实取舍的决策。

如果新结论与现有术语或 ADR 冲突，明确指出冲突并保留原文，不静默覆盖。
